# 正弦曲線變形實驗室

高中三角函數「平移與伸縮」的互動教學頁。拉動四個滑桿，即時看

$$y = A\sin\bigl(B(x - C)\bigr) + D$$

的圖形如何被垂直拉伸、水平壓縮、左右平移、上下抬起 —— 每個參數都會在圖上畫出自己的幾何意義。

**線上版本：** https://h23114.github.io/sin-cos/

---

## 特色

| 參數 | 意義 | 圖上標註 |
|---|---|---|
| `A` | 振幅（垂直伸縮） | 中線到波峰的雙箭頭 ＋ $y = D \pm \lvert A\rvert$ 包絡虛線 |
| `B` | 角頻率（水平伸縮） | 橫跨一個完整週期的雙箭頭，兩端有垂足 |
| `C` | 相位（水平平移） | 從 $x = 0$ 指到 $x = C$ 的箭頭 |
| `D` | 中線（垂直平移） | 貫穿全圖的中線虛線 ＋ 從 $y = 0$ 抬起的箭頭 |

- **即時讀數**：振幅、週期、水平平移、中線、值域。
- **教學路徑**：8 個「一次只動一個參數」的預設，配合每個參數的自動掃描動畫。
- **對照練習**：隨機產生一條隱藏參數的曲線，讓學生用滑桿疊上去。
- 淺色／深色主題、響應式版面、鍵盤可操作（滑桿支援方向鍵）。

## 兩個刻意的教學設計

### 1. 寫成 $B(x-C)$ 而不是 $Bx - C$

高中生最常見的錯誤：看到 $\sin(2x - \pi/3)$ 直覺回答「右移 $\pi/3$」。

$$\sin(2x - \tfrac{\pi}{3}) = \sin\bigl(2(x - \tfrac{\pi}{6})\bigr)$$

真正的平移是 $\pi/6$。原因是平移量定義在 **$x$ 本身**上，而橫軸已先被壓縮成 $1/B$ 倍，所以必須先把 $B$ 提出來才讀得到平移量。這也是**伸縮一定要排在平移之前**的理由 —— 兩者順序一交換，平移量本身也會被縮放。

頁面下方有專門的說明區塊，附一鍵跳到該情境的按鈕。

### 2. 練習模式比對「圖形」而不是「參數」

$(A, B, C, D)$ 對曲線並不唯一（例如 $A < 0$ 等價於相位平移半個週期），比對參數會把正確答案判成錯。因此練習模式改為在 $[-2\pi, 2\pi]$ 上取 240 點計算

$$\max_x \lvert f(x) - g(x)\rvert < 0.15$$

數學上誠實，學生也不會遇到「圖明明疊上去了卻說我錯」的情況。

## 使用方式

**線上**：直接開 https://h23114.github.io/sin-cos/

**離線（教室電腦、投影用）**：下載 `index.html`，雙擊即可。整份是單一檔案，沒有建置步驟、沒有相依套件。唯一的網路請求是 Google Fonts；斷網時會自動退回系統字型，功能完全不受影響。

## 技術說明

- 單一 HTML 檔，原生 SVG 繪圖，無任何第三方函式庫。
- 圖形以實際 CSS 像素重繪（`ResizeObserver` 驅動），因此文字在任何視窗寬度下都保持銳利，不會被 viewBox 縮放糊掉。
- 標註文字有自動避讓機制：量測 bounding box 後逐一上下錯開，確保不重疊也不超出畫框。已針對 1400 組 $(A,B,C,D)$ 參數組合驗證。
- 週期比可視範圍寬時，箭頭只在未被裁切的一端畫箭頭並標示「延伸出畫面」，避免用一段不完整的箭頭謊稱是一個完整週期。
